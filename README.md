# ismaeljarias.github.io

The general site for every game (GitHub Pages user site, https://ismaeljarias.github.io/).

- `app-ads.txt`: the AdMob seller line, shared by every game with ads (Google reads it at the root of the developer website set in each Play listing).
- `index.html`: one section per game with its links.

Each game's privacy policy has its own repo, published under this site:

| Game | Repo | URL |
|---|---|---|
| Port Dynasty: Family Empire | `Ismaeljarias/port-dynasty-privacy` | https://ismaeljarias.github.io/port-dynasty-privacy/ |
| DadaBoom | `Ismaeljarias/dadaboom-privacy` | https://ismaeljarias.github.io/dadaboom-privacy/ |

Local layout (`~/Desktop/Games/websites/`): `ismaeljarias.github.io/` (this repo), `<game>/privacy/` (each game's privacy repo), `_archive/` (old copies).

- `blockseed-privacy/`: Block Seed's privacy policy, a folder of this site (no separate repo), live at https://ismaeljarias.github.io/blockseed-privacy/
